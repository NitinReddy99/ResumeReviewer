# ResumeReviewer

An AI-inspired Smart Resume Screener built with React and Java Spring Boot.

## Features
- Upload PDF or text resumes
- Extract candidate name, skills, experience and education
- Compare candidates against a job description
- Weighted skill and keyword matching
- Candidate ranking and shortlist recommendations
- Explainable strengths and skill gaps
- Elegant analytics dashboard

## Architecture
- `frontend/` — React + Vite dashboard
- `backend/` — Java 21 + Spring Boot REST API
